# MakerLab Tools v3 App

This is the Next.js application for MakerLab Tools v3.

For full architecture, user flows, API docs, and Airtable table diagrams, see:
- `../README.md`

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Useful commands

```bash
npm run build
npm run start

npm run sync:pull
npm run sync:images
npm run sync:push
npm run sync:status
```
